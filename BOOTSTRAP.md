# BOOTSTRAP.md - Skill Setup

This file provides first-use guidance for the `software-development-team` skill in Qoder.

## Quick Start

1. Review `SKILL.md` for the skill workflow
2. Review `assets/constitution.md` and `assets/tech.md` for governance
3. Adjust `assets/tech.md` to match your project's actual technology stack
4. Run `python scripts/check_skill_integrity.py .` from the skill root to verify integrity

## Governance Setup

- Edit `assets/constitution.md` to define your project's development principles
- Edit `assets/tech.md` to specify your actual frontend/backend/infrastructure stack
- The skill will treat these as mandatory constraints for all roles

## When Done

This file can be deleted once the skill is configured for your project.
