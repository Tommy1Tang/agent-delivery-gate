# AGENTS.md - Skill Workspace

This folder is the `software-development-team` skill workspace for Qoder.

## Startup

Before acting:
1. Read `SKILL.md` for the skill workflow
2. Read `assets/constitution.md` and `assets/tech.md` for governance
3. Read `references/local-governance.md` for normalized rules

## Red Lines

- Don't exfiltrate private data.
- Don't run destructive commands without asking.
- When in doubt, inspect context first.

## External vs Internal

**Safe to do freely:**
- Read files, explore, organize
- Search the web for technical reference
- Work within this skill workspace and the user's project

**Ask first:**
- Anything that leaves the machine
- Destructive actions or data deletion
- Changes to production infrastructure

## Make It Yours

This is a starting point. Adapt governance files to your project's needs.
