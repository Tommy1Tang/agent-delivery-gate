## §A 用例字段标准（系统级验收适用）

用例采用九字段结构，便于与可追溯性矩阵、缺陷统计、覆盖率分析对齐：

| 字段 | 说明 |
| --- | --- |
| 编号 | 全局唯一，建议形如 `<模块>-<子模块>-<序号>` |
| 模块 | 一级业务模块 |
| 子模块 | 二级功能分组 |
| 用例名称 | 一句话概括测试目标 |
| 前置条件 | 系统状态、数据状态、用户角色、外部依赖状态 |
| 操作步骤 | 编号化、可独立复现 |
| 预期结果 | 与步骤一一对应，覆盖 UI、数据、提示、状态变化 |
| 用例等级 | P0 阻断 / P1 严重 / P2 一般 / P3 建议 |
| 标签 | 用例归类，如「入口&UI」「排序」「删除」「自定义输入」「兼容」「安全」 |

## §B 黑盒用例设计套路速查

设计用例时按以下套路逐项覆盖，避免漏测：

- **等价类划分**
  - 合法字符：本国语言、英文、数字、混合
  - 非法字符：中文（在仅限英文场景）、特殊字符、希腊字母、罗马数字、空格（首/中/末）、空值
- **边界值**
  - 长度 = 最大允许 / 最大允许 + 1 / 最大允许 - 1
  - 数值 = 上限 / 下限 / 上限 + 1 / 下限 - 1
  - 长度等于列宽的截断显示与悬浮展开
- **状态矩阵**
  - 模式 A × 模式 B 的 4 象限组合（如 normal × stat、在线 × 离线、登录 × 未登录）
  - 每象限均需独立用例，禁止用「同上」省略
- **模式遍历**：当系统支持多种交互模式（编号模式 / 序列模式 / 扫码模式 等）时，每模式跑一遍核心流程
- **流程穿插**：长流程「过程中」+ 长流程「结束后」两类切入点都要有用例
- **状态标识**：异常 / 屏蔽 / 遮蔽 / 状态颜色 / 角标 等视觉标识必须有专门用例
- **排序三步法**：第 1 次点击列标题升序 → 第 2 次降序 → 第 3 次恢复默认
- **重复与压力**：连续多次执行同一操作、快速反复点击、并发触发
- **占用与冲突**：相同 ID / 相同位置 / 相同资源被占用时的提示与拒绝
- **持久化校验**：操作完成后退出/重启系统，重新进入验证数据未丢失

## §C 阶段适配建议

根据当前所处阶段裁剪用例集合：

| 阶段 | 重点用例 | 可裁剪 |
| --- | --- | --- |
| 开发封版 | 核心业务主干流程（冒烟）、本阶段 P0 功能、已修复缺陷回归 | 边界、异常、组合场景、低优先级 |
| 开发结题 | 新增功能全量、跨模块组合场景、全功能回归 | — |
| 确认结题 | 全功能 + 非功能（性能、可靠性、可用性、兼容性、多语言） | — |
| 上市维护 | 变更点精准用例 + 影响域回归 + 主干冒烟 | 与变更无关的低风险全量回归 |
