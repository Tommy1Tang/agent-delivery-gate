## 目标用户与主路径

| 角色 | 主要页面 | 单次会话时长 | 关键诉求 |
| --- | --- | --- | --- |
| ROLE-01 生产计划员 | 工单看板、排程甘特、追溯查询 | 连续 2 小时以上 | 排程快、冲突可见、调整可追溯 |
| ROLE-02 车间班组长 | 工单详情与报工、设备状态看板 | 高频短时（每次 ≤ 2 分钟） | 任务清晰、报工少录入、异常可快速上报 |
| ROLE-03 操作工 | 工单详情与报工 | 高频短时（每次 ≤ 1 分钟） | 字段最少、可扫码、按键可达 |
| ROLE-04 质检员 | 检验录入、处置审批、追溯查询 | 中频（每次 3 ~ 8 分钟） | 判定留痕、边界提示清晰、不合格闭环 |
| ROLE-05 设备管理员 | 设备状态看板、告警处理 | 中频 | 故障定位快、告警分级明确 |
| ROLE-06 系统管理员 | 系统管理区（用户、角色、审计日志） | 低频 | 权限可控、审计可查不可改 |

主路径（P0 旅程，与 AC-001、AC-005、AC-009、AC-019、AC-023、AC-026 对应）：

1. 计划员登录 → 工单看板创建工单 → 下达 → 排程甘特生成排程任务（冲突可见）。
2. 班组长在工单详情完成投料与开工 → 操作工报工，数量报满后工单转「待检」。
3. 质检员在检验录入页录入检验项 → 判定；不合格时进入处置审批页发起返工 / 让步 / 报废。
4. 计划员在工单看板关闭工单；全过程可在追溯查询页按批次或工单双向查询。

## 信息架构和导航关系

```text
登录 P-01
└─ 主框架（顶栏 + 侧边导航 + 面包屑）
   ├─ 工单管理  P-02 工单看板 ──→ P-03 工单详情与报工
   │                              └─→ P-07 检验录入（待检工单入口）
   ├─ 生产排程  P-04 排程甘特视图
   ├─ 设备监控  P-05 设备状态看板
   ├─ 批次追溯  P-06 追溯查询（支持从 P-02 / P-03 / P-07 带参跳转）
   ├─ 质量检验  P-07 检验录入 ──→ P-08 处置审批（判定不合格时）
   └─ 系统管理  P-09 用户 / 角色 / 审计日志
```

导航规则：

- 侧边导航按角色可见性裁剪：ROLE-03 仅显示「工单管理」；ROLE-06 仅显示「系统管理」；越权路由由前端路由守卫拦截并跳转 403 页。
- 面包屑最多三级，末级为当前对象（如「工单管理 / WO20260401-0007 / 报工」）。
- 跨页带参跳转使用查询参数（`workOrderNo`、`materialBatchNo`、`inspectionNo`），刷新后仍可还原上下文。
- 未保存表单在路由离开前触发确认对话框；已提交的操作不做二次拦截。

## 组件库架构

### Design Token 系统

- 颜色 Token：主色 `--mes-color-primary: #1B6FE0`；主色悬浮 `#3A83E8`；主色激活 `#1557B0`；语义色 成功 `#16A34A`、警告 `#D97706`、危险 `#DC2626`、信息 `#64748B`；中性色 主文本 `#1F2937`、次文本 `#4B5563`、辅助文本 `#6B7280`、边框 `#D9DEE7`、分割线 `#EDF1F7`、页面底色 `#F5F7FA`、卡片底色 `#FFFFFF`；设备状态专用色 RUNNING `#16A34A`、IDLE `#D97706`、DOWN `#DC2626`、MAINTENANCE `#2563EB`、OFFLINE `#94A3B8`。
- 排版 Token：字体族 `"Segoe UI", "Microsoft YaHei", system-ui, sans-serif`；字号 12 / 14 / 16 / 20 / 24 / 30px；字重 400 / 500 / 600；行高 1.5（正文）、1.3（标题）；数字与时间使用等宽特性 `font-variant-numeric: tabular-nums`。
- 间距 Token：基础单位 4px，梯度 4 / 8 / 12 / 16 / 24 / 32 / 48px；页面外边距 24px，卡片间距 16px，表单项间距 16px。
- 圆角、边框、阴影、动效和层级 Token：圆角 2px（标签）/ 4px（控件）/ 8px（卡片、抽屉）/ 999px（圆点）；边框 1px `#D9DEE7`；阴影 `--mes-shadow-1: 0 1px 2px rgba(15,23,42,.06)`、`--mes-shadow-2: 0 4px 12px rgba(15,23,42,.10)`、`--mes-shadow-3: 0 8px 24px rgba(15,23,42,.14)`；动效时长 150ms（状态切换）/ 250ms（抽屉与对话框），缓动 `cubic-bezier(.4,0,.2,1)`；层级 z-index 表：下拉 1000、吸顶表头 1010、抽屉 2000、对话框 2100、全局提示 3000、全屏加载 4000。
- Element Plus 主题变量、项目 CSS 变量或 scoped class 映射：Element Plus 变量覆写集中在 `src/styles/element-overrides.scss`（`--el-color-primary`、`--el-border-radius-base`、`--el-font-size-base`、`--el-table-row-height` 等），项目语义变量集中在 `src/styles/tokens.scss` 并以 `--mes-*` 前缀暴露；禁止在 `.vue` 文件内硬编码色值，scoped 样式只允许引用 Token 变量。

## 表单、表格、筛选、弹窗和通知模式

**表单**

- 统一使用 `ElForm` + `ElFormItem` + `rules`，提交前调用 `formRef.validate()`；校验失败时滚动并聚焦首个错误字段。
- 报工表单字段上限 6 个（RSK-04）：工单号（只读）、合格数量、报废数量、报废原因（报废数量 > 0 时必填）、版本号（隐藏域，乐观锁）、备注；支持扫码枪键盘模拟输入并回车提交。
- 工单创建表单：产品编码（可搜索下拉，来自主数据）、计划数量、单位、计划开始时间、计划结束时间、优先级、备注；计划开始时间选择器禁用当前时间 + 2 小时之前的时段，从输入端降低 `START_TOO_SOON` 概率。
- 检验录入表单：逐项录入实测值，数值型检验项在输入框右侧常驻显示上下限提示（如 `10.000 ~ 20.000 mm`），失焦即时校验。
- 处置表单：处置类型（返工 / 让步接收 / 报废）、数量、原因（10 ~ 200 字）、审批人；选择「报废」时展示双方审批提示条。

**表格**

- `ElTable` + `ElPagination` 组合，服务端分页与排序；默认每页 20 条，可选 20 / 50 / 100。
- 列优先级：窄屏按「状态 → 数量 → 时间」保留，操作人、备注等列可隐藏；所有列宽固定，长文本截断并悬浮展开。
- 状态列使用 `MesStatusTag`；超期未判定、待处理告警在行首显示 3px 语义色条。
- 批量操作仅在勾选后启用；翻页后清空选择，选择数与操作按钮联动。

**筛选**

- 筛选区默认展示 2 行，条件超过 4 个折叠为「展开更多」；筛选变更不自动请求，「查询」按钮触发，支持「重置」恢复默认。
- 时间范围筛选默认最近 7 天；追溯到 365 天上限时在超出时给出内联提示（对应 `TIME_RANGE_TOO_LARGE`）。
- 筛选条件同步至 URL 查询参数，便于分享与刷新还原。

**弹窗与抽屉**

- 轻量表单（工单创建与编辑、排程调整）使用 `ElDrawer`（宽 560px，右侧滑入）；确认类与详情类使用 `ElDialog`（宽 480 ~ 720px）。
- 关闭时重置表单状态并保留「未保存」二次确认；破坏性操作（取消工单、报废处置、关闭告警）必须二次确认并明确写出对象与后果。

**通知**

- 操作成功用 `ElMessage.success`（3 秒自动消失，连续操作合并为一条计数提示）；失败用 `ElMessage.error`（6 秒，含错误码与可复制文本）。
- 冲突类失败（乐观锁、排程冲突、幂等拒绝）使用 `ElMessageBox` 说明冲突对象并提供「刷新数据」动作，用户已填内容保留在表单中。
- 后台类结果（导出、批量下达）使用右上角通知卡片，展示进度与结果条数；不做阻塞式加载。

## 交互状态

- 加载态：页面级使用 `ElSkeleton`；表格与卡片使用 `v-loading` 遮罩；按钮提交后进入 loading 且禁用重复点击；设备看板使用 10 秒轮询 + 局部刷新，不整页闪烁。
- 空态：使用 `ElEmpty`，文案按场景定制（如「当前筛选条件下没有工单」「该批次尚无投料记录」），并提供下一步动作按钮（新建工单 / 查看全部）。
- 错误态：字段级错误显示在字段下方；表单级错误显示在表单顶部 `ElAlert`；页面级错误（接口 5xx）显示重试区块并保留上下文；权限错误（403）跳转 403 页并说明所需角色。
- 禁用态：不满足前置条件的操作按钮禁用并用 `ElTooltip` 说明原因（如「未完成投料，无法开工」对应 `MATERIAL_NOT_FED`）；禁用按钮保持可达但不能聚焦触发。
- 成功反馈：写操作成功后刷新局部数据并以状态标签变化作为主要反馈；报工成功后滚动至最新状态时间线条目。
- 确认/撤销：破坏性操作二次确认，不提供撤销；可逆的排程调整提供 5 秒内「撤销」提示（后端以调整记录回滚实现）。

## 响应式规则

- 桌面优先：主设计分辨率 1920×1080；1280×720 为验收最低分辨率，低于该尺寸仅保证不破版并提示放大窗口。
- 侧边导航：≥1280px 展开 200px；1024 ~ 1279px 自动折叠 64px（仅图标 + 悬浮展开）；用户手动折叠状态本地记忆。
- 表格：1024 ~ 1279px 隐藏低优先级列；<1024px 表格切换为纵向堆叠卡片式只读视图。
- 甘特视图：时间轴按小时刻度，窗口宽度不足时横向滚动，左侧设备列固定；不支持拖拽时提供「调整」对话框作为等价入口。
- 筛选区：<1280px 折叠为单列；操作栏按钮保持固定宽度，不因文案换行导致跳动。

## 响应式设计框架

- 容器规则：内容区 100% 宽度，最大 1680px 居中；页面内边距 24px，<1280px 降为 16px；卡片间距 16px 保持不变。
- 断点规则：640px / 768px / 1024px / 1280px（沿用既有断点映射），另设 1600px 宽屏优化点；<768px 不在交付范围，仅保证只读降级与提示。
- 网格重排：设备卡片与统计卡片使用 12 列栅格，≥1600px 每行 4 个、1280 ~ 1599px 每行 3 个、1024 ~ 1279px 每行 2 个、<1024px 每行 1 个；表单单列转两列的阈值同为 1280px。
- 导航、筛选、操作栏重排：导航折叠规则见上；筛选区在窄屏折叠为抽屉；操作栏在窄屏保留主操作，次要操作收进「更多」下拉。
- 表格、表单、详情区适配：表格列显隐优先级固定为 状态 → 数量 → 时间 → 操作人 → 备注；详情区由两列转为单列；表单标签在窄屏由右对齐改为顶部对齐。
- 固定格式元素稳定尺寸：状态标签最小宽度 72px、按钮高度 32px、表头高度 40px、分页器高度 32px、图标按钮 32×32px、甘特行高 36px；这些元素在任何断点下不得因内容变化改变尺寸。

## 无障碍要求

- 色彩对比度：正文与背景 ≥ 4.5:1，18px 以上大字与状态标签文字 ≥ 3:1；状态标签不使用纯色差表达语义，统一附带文字（如 `运行` / `停机`），避免仅靠颜色区分。
- 键盘导航：全部功能可用键盘完成，Tab 顺序遵循「导航 → 筛选 → 表格 → 分页 → 操作」；表格支持方向键移动、回车进入详情、Esc 关闭抽屉与对话框。
- 屏幕阅读器支持：语义化 HTML 与 ARIA 标签；`ElTable` 提供 `aria-label`；状态标签补充 `aria-live="polite"` 的变更播报；甘特视图提供等价表格视图（`role="table"`）供读屏使用。
- 焦点管理：焦点环 2px 主色描边且不被移除；打开对话框后焦点进入首个可交互元素，关闭后回到触发元素；抽屉与对话框实现焦点陷阱。
- 触控目标与文本缩放：图标按钮视觉尺寸 32×32px，命中区外扩至 44×44px；支持浏览器文本缩放至 200% 不出现内容裁切；尊重 `prefers-reduced-motion`，关闭非必要动效。
- 错误预防：必填项有明确标识与说明；数量、时间类输入提供边界提示；破坏性操作二次确认；服务端错误码附可读文案与处理建议。

## 与现有组件体系的对齐

- 优先使用 Element Plus 既有组件，仅在语义与复用明确时二次封装（`MesDataTable`、`MesStatusTag`、`MesSectionCard`），不引入新的 UI 框架与图标库。
- Element Plus 变量覆写集中在 `src/styles/element-overrides.scss`，项目语义变量集中在 `src/styles/tokens.scss`；组件内禁止散落硬编码色值与尺寸。
- 表单校验统一使用 `ElForm` 的 `rules` 机制，服务端错误码到文案的映射集中维护于 `src/utils/errorCode.ts`，页面不硬编码错误文案。
- 接口调用统一收敛在 `src/api/`，`.vue` 文件内不直接调用 `fetch` 或 `axios`；类型定义与 `src/types/` 同步。
- 新增页面必须同步 `router/index.ts`（路由、菜单项、权限守卫），并按角色配置菜单可见性。
- 状态枚举与后端契约保持逐字一致（`CREATED` / `RELEASED` / `SCHEDULED` / `IN_PROGRESS` / `PAUSED` / `PENDING_QC` / `BLOCKED` / `CLOSED` / `CANCELLED` 等），文案映射集中在 `MesStatusTag` 内。

| 错误码 | 呈现方式 | 示例文案 |

| 未映射错误码 / 5xx | 页面级错误区块 + 重试 | 服务暂时不可用，请稍后重试（错误号可复制） |
