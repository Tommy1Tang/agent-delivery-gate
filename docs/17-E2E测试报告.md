## 7. 未验证项

| 未验证内容 | 原因 | 验证归属与证据 |
| --- | --- | --- |
| AC-006 并发报工乐观锁冲突（`VERSION_CONFLICT`） | 双会话并发在浏览器级 E2E 中时序不可稳定复现 | API 级集成测试覆盖（双请求并发提交，断言 409 与数量不重复累加） |
| AC-010 排程无可用设备（`NO_ELIGIBLE_EQUIPMENT`） | 需要构造工艺路线无匹配设备的种子数据，与主旅程种子冲突 | API 级集成测试覆盖 |
| AC-011 同设备排程冲突（`SCHEDULE_CONFLICT`） | 甘特拖拽的冲突提示需人工观察时间轴，自动化断言成本高 | API 级集成测试覆盖 + 人工探索测试 1 轮 |
| AC-013 / AC-015 设备上报、看板刷新与告警升级关闭 | 需要模拟网关持续上报与 10 分钟告警升级窗口，超出本次执行时长预算 | API 级集成测试 + 设备网关模拟器脚本覆盖 |
| AC-023 / AC-025 检验项完整性与不合格拦截下游 | 需要构造含超限项的检验单与不合格处置数据 | API 级集成测试覆盖（含上下限边界值与容差） |
| AC-026 不合格品处置闭环（含 SCRAP 双人审批） | 涉及 ROLE-01 与 ROLE-05 双角色切换与审批时序 | API 级集成测试 + 手工验收 1 轮 |
| AC-028 数据范围隔离、AC-029 审计不可改删 | 越权与篡改场景属安全评审范围 | 安全评审自动化越权用例覆盖（`docs/15-安全评审.md`） |
| Excel 导入与追溯报告导出 | 下载文件校验需独立测试夹具 | 集成测试覆盖（文件内容断言） |
| 移动端与低分辨率适配 | 需求范围外（仅桌面浏览器，1920×1080 起） | 不在验证范围 |
| 压测与性能指标（NFR-001 ~ NFR-003、AC-030） | 属性能测试范围，非浏览器 E2E | `docs/06-性能优化说明.md` PERF-001 ~ PERF-007 |

## 8. 残余风险

| 编号 | 风险 | 影响 | 缓解 |
| --- | --- | --- | --- |
| E2E-R01 | 本次 E2E 未覆盖的 10 条 P0 验收标准依赖其他测试层级结论 | 若其他层级报告滞后，发布门禁缺少完整证据链 | 发布前由 Quality Gate Engineer 汇总集成测试与安全评审结论，与本报告合并评审 |

| E2E-R03 | 负向用例的种子数据为构造数据（如冻结批次），与现场真实异常分布不同 | 未覆盖的组合在真实场景可能触发未预期提示 | 试运行期收集现场真实异常案例，补充为回归用例 |
| E2E-R04 | 仅覆盖 Chromium；Chrome 仅人工对照 1 轮 | Edge 特定渲染差异未被自动化捕获 | 按 NFR-008 在发布前对 Edge 最新两个大版本执行 1 轮人工冒烟 |
| E2E-R05 | 用例依赖种子脚本与固定工单号，跨日执行需重新 seed | 用例在跨日或并发执行时可能相互干扰 | CI 中按用例串行执行并强制 seed；工单号由种子脚本按当日日期生成 |
