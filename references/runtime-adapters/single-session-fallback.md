# Single Session Fallback Runtime Adapter

Use this adapter only when the runtime cannot dispatch independent role sessions.

## Rules

- Explicitly disclose fallback mode.
- Preserve role sequence and role boundaries.
- Do not claim that fallback is equivalent to independent sessions.
- Keep a role-by-role evidence ledger.
- Run the same quality gates before final delivery.

## Required Disclosure

The final summary must include:

- why fallback was used
- which roles were simulated in sequence
- which outputs were produced
- which validations were run
- remaining risks caused by fallback
